# Screen Recorder

macOS 轻量录屏工具，使用熟悉的悬浮工具栏选择屏幕、窗口或区域，将系统声音与可选麦克风旁白录入 MOV 文件。

系统声音独立于麦克风，不需要虚拟声卡，也不改变默认音频设备、音量、蓝牙配对或 AirPods 自动切换设置。窗口录制的“系统声音”包含其他应用的声音；受平台保护的内容不能保证采集。

面向 Apple Silicon 和 macOS 26。使用 Swift、AppKit、ScreenCaptureKit 与 AVFoundation，不依赖网络服务或第三方媒体框架。

项目正在实现，当前文档不代表功能已经完成。默认画质的同机系统对照、完整交互与资源释放均需以实际录制结果确认。
