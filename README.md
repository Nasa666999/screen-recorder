# Screen Recorder

macOS 轻量录屏工具，使用熟悉的悬浮工具栏选择屏幕、窗口或区域，将系统声音与可选麦克风旁白录入 MOV 文件。

系统声音独立于麦克风，不需要虚拟声卡，也不改变默认音频设备、音量、蓝牙配对或 AirPods 自动切换设置。默认录入所有桌面的系统声音，可主动选择仅录指定应用或关闭。应用过滤仍包含同一应用在其他桌面和窗口的声音，不提供按 Space 隔离声音的承诺；受平台保护的内容不能保证采集。

“系统声音 → 选择应用（可多选）”按浏览器、音乐与播客、视频与媒体、通话与通讯分组，列出已安装的对应应用，包括 Safari、Chrome、酷狗音乐、音乐、播客和 QuickTime Player 等。普通编辑器、终端和管理工具不出现在此列表；仍可通过“全部系统声音”录入其它应用的声音。未运行的应用也会列出并标记，录制前需先打开所选应用。所选应用不可采集时明确停止启动，不自动扩大到全系统声音。“仅所选应用”模式下，移除不可用来源后若没有剩余选择，需要重新指定来源。

面向 Apple Silicon 和 macOS 26。使用 Swift、AppKit、ScreenCaptureKit 与 AVFoundation，不依赖网络服务或第三方媒体框架。

使用屏幕、窗口或区域模式选择来源，单击屏幕或窗口只选中来源，按“录制”才开始，从菜单栏停止。工具栏保持单行布局，模式说明在鼠标悬停图标时出现。窗口选中后保留边框，也可在“选项 → 选择录制窗口”选择来源。画质默认“标准（1080p）”，保持来源比例且不放大小画面；帧率默认固定 30 fps，可主动选择 60 fps。同一次录制的画布、帧率上限、编码格式和码率预算在启动时固定，不随屏幕刷新率改变。系统声音默认开启，麦克风默认为“无”。画质、帧率、倒计时、保存位置、录前确认及缩略图均可在“选项”调整。成品提供应用内播放、剪切拼接、系统分享、缩略图拖动复制及移到废纸篓。

区域画好并松开鼠标后，框外可正常操作桌面；在框内按住鼠标左键可移动整个选区，拖动八个控制点调整大小。选区使用黑白双层边框、带深色轮廓的白色控制点及深底尺寸标签，在浅色、深色和彩色背景上都能辨认。需要重画时使用“选项 → 重新框选区域”。放大镜只在实际拖动选区或控制点时读取像素，松开后停止取样；等待点击“录制”期间保留边框，不使用全屏遮罩拦截框外桌面。

窗口模式按选中的系统窗口表面录制，明确排除未选中的关联子窗口。浏览器可能将正文与顶部栏分为多个表面，选择正文时不把关联的标签栏、地址栏或书签栏合并进成片。范围提示与原窗口一起移动；窗口布局或尺寸改变后应重新选择。不需要辅助功能权限读取网页结构。

正在录制时菜单栏显示闪烁的小红点，点击即可停止。全屏、窗口和区域录制保留醒目的范围边框，鼠标可穿透，边框不进入成片。窗口边框跟随原窗口移动和缩放；原窗口最小化或不在当前桌面时隐藏边框，独立窗口录制仍继续。框选和调整区域时提供像素放大镜、像素坐标和尺寸；放大镜复用附近的原始像素缓存并后台刷新，鼠标移动时直接裁出对应位置，不要求停住鼠标后才显示。方向键移动一像素，`Shift` 加方向键移动十像素，`Option` 加方向键调整右侧或上侧边缘。

全屏和区域默认使用一条采集流；窗口模式使用独立窗口视频和一条系统音频流。仅录指定应用声音时，三个画面模式均使用单独的应用音频流，不改变画面范围。系统声音和麦克风统一到同一时间线，混为普通播放器直接播放的一条 AAC 音轨。一个会话最多两条流。实时采集回调只交付有限样本，不等待编码或磁盘；媒体队列最多持有三个待处理视频和六十四个待处理音频样本，待处理样本合计不超过 128 MiB，单个音频块与混音缓存均限两秒。单个样本超过字节预算时明确拒绝当前规格。该预算约束应用的待处理样本，不代表硬件编码器和系统服务的全部内存。编码后的内容持续写入目标目录中的未完成 MOV，媒体块以一秒为写入偏好，不把整部视频保存在内存。视频拥塞时丢弃尚未编码的画面，音频持续积压时明确结束并保留已录内容，不通过变速或无限缓存继续。录屏文件明确声明按原始时间线正常速度播放，视频与末帧均按固定帧格输出。

停止后分别等待 MOV 完成和全部采集流释放。异步调用已发出不代表保存成功；超时会显示实际状态并阻止新录制，不通过重启系统音频或录屏服务收尾。已有文件不覆盖，封装失败的文件不当作成品发布。

## 剪辑与拼接

从工具栏“选项 → 剪辑与拼接…”、菜单栏右键菜单或录后预览打开剪辑窗口；应用当前激活时也可按 `⌘O`。可以一次添加多个本地视频，或把文件从 Finder 拖入片段列表，按列表顺序拼接。

播放后用“设为起点 / 设为终点”标记范围，也可拖动滑块或输入时分秒。支持逐帧查看、保留选区、删除选区、在播放处分割、移除片段、上移 / 下移、撤销 / 重做和预览全部。片段列表支持右键或双指菜单，提供播放片段、上移、下移、移除、撤销和重做。“移除”与下方按钮相同，只移除实际点击的片段并可撤销；空白区域不移除已有选中片段。删除片段中间的选区时，其前后内容成为连续的两个保留片段。编辑只保存来源引用和时间范围，原文件始终不改动。

选择第二段或后续片段后，可“与上一段自动对齐”。应用只分析前段最后三分钟和后段最初三分钟，通过声音对应关系与画面核对寻找重复内容；没有可用共同声音时尝试连续画面匹配。识别结果先显示为建议，可以预览接缝前后三秒，再采用或撤销。无共同内容、重复画面或多个相似位置时要求手动设置，不能恢复未录下的内容，也不能保证任意两段都能自动无缝连接。

“导出新视频…”（`⌘S`）默认按录屏规则 `yyyy-MM-dd at HH.mm.ss.mov` 命名，同一秒重名时追加序号。它将当前列表直接封装为新的 MOV，使用来源的压缩视频数据，不重新编码、缩放、插帧或统一帧率；各段原始帧时间与清晰度保留，源帧率不同也保持各段原时序。直接拼接要求画面尺寸、方向和视频编码一致，支持单视频轨道及至多一条声音轨道；规格不兼容时明确提示。没有声音的片段保留相应的静音时段。

预览与导出音量可保持原始、放大两倍、放大四倍、自动放大或自定义 1 到 100 倍（支持小数）。两倍、四倍与自定义直接按所选倍数放大当前导入视频，未进入软限幅范围的采样保持指定倍数（两倍约增加 6 dB，四倍约增加 12 dB），过高峰值单独软限幅并保留编码余量；瞬时高峰不会降低整片的指定倍数。自动模式先扫描整片声音峰值，采用统一增益并预留两分贝峰值余量，最多增加 24 dB，峰值已接近上限时保留原音量。音量处理不改变采样时间或播放速度，启用放大时只将声音重新编码为 48 kHz 双声道 AAC，视频数据和帧时序保留。“预览全部”和“试听接缝”按当前音量设置准备声音，使用与导出相同的放大及限幅流程；准备期间可取消，更改音量后再次点击预览即可试听新效果。“当前片段”播放来源原声音。预览不生成临时视频，切回当前片段、替换预览或关闭窗口时释放对应临时声音。

导出持续落盘，不把整个视频读入内存；边界识别的缓存只随固定搜索范围增长。导出先写同目录临时文件，完成后复验时长、轨道和来源身份，再以新文件名发布。已有文件、来源视频与其他同名文件均不覆盖；失败或取消会清理本次未完成的输出。

## 构建与运行

需要 Apple Silicon、macOS 26 或更高版本，以及包含 macOS 26 SDK 的 Apple Command Line Tools 或 Xcode。构建默认使用钥匙串中名为 `Screen Recorder Local Development` 的固定代码签名身份；也可通过 `SIGN_IDENTITY` 指定已有身份。

```sh
make build
open "build/Screen Recorder.app"
```

首次创建桌面启动入口可运行 `make desktop-shortcut`。入口指向项目的构建应用，重新构建后仍可使用；已有同名文件时不覆盖。图标使用矢量脚本生成完整尺寸，修改图标源后运行 `make icon` 即可更新。

首次选择来源时，按 macOS 提示授予“屏幕与系统音频录制”权限；只有主动选用麦克风才请求麦克风权限。选择其他保存位置后记住该目录，不改动桌面的 iCloud 设置。

调用快捷键为 `⌘⇧5`。该组合通常被系统“截屏”占用，用户可在系统设置解除原绑定后，从本应用菜单栏右键菜单重试注册；应用不改写系统绑定。停止快捷键为 `⌃Esc`（Control + Esc），冲突时使用本应用菜单栏停止按钮。快捷键只在应用运行时有效，停止快捷键仅在录制相关阶段注册，空闲时释放。

需要在应用退出后仍通过 `⌘⇧5` 启动时，可在 macOS“快捷指令”创建打开本应用的入口，并绑定该组合；须先关闭系统截屏的同一绑定。工具栏的 `×` 退出整个应用，正在录制或保存时先完成收尾；`Esc` 取消当前选择。

使用 `make build SIGN_IDENTITY="签名身份名称或证书指纹"` 可指定固定身份，后续构建应持续使用同一证书；身份缺失时在覆盖应用前停止，不自动切换到临时签名。证书和私钥由本机钥匙串管理，不随源码或应用归档分发。首次由临时签名切换为固定签名后，需要在系统设置更新一次本应用的授权并退出重开。

明确指定 `SIGN_IDENTITY=-` 时仍可使用临时签名，但重新编译会改变该应用的身份，macOS 可能要求重新授权。系统“录屏与系统录音”开关与直接访问屏幕的系统确认并非同一提示，固定签名不承诺免除系统定期确认或用户撤销权限后的提示。应用不直接修改系统权限数据库。跨机器分发仍需相应签名与公证。

## 能力边界

全屏和区域模式录制显示器当前显示的桌面，切换 Space 会跟随显示器改变画面；不能把已经切走的整个 Space 作为持续更新的后台桌面录制。需要跨桌面继续采集原内容时选择窗口模式，它锁定原窗口，不切换到新桌面的窗口。选择遮罩只属于当前桌面，切换桌面会取消未完成选择，已经开始的窗口录制继续运行。工具栏首次位于屏幕底部中央，拖动后记住位置，重开应用继续恢复。

“标准（1080p）”将输出限制在 1920×1080 的长短边范围内，竖屏对应 1080×1920，保持比例且不放大小画面。“自动（原始分辨率）”保留来源像素尺寸，不施加该缩放上限。优先使用 HEVC 硬件编码，SDR 当前尺寸不可用时选择 H.264 硬件编码，保持相同分辨率，容器均为 MOV；HDR 只使用 HEVC。1920×1080、30 fps、SDR 的视频目标平均码率为 HEVC 3.5 Mbps 或 H.264 5 Mbps，按实际像素数缩放；60 fps 和 HDR 使用更高预算。码率为平均目标，实际体积随画面复杂度变化，有损编码不承诺逐像素相同。全部硬件编码路径都不接受当前规格时明确报错，由用户选择画质、帧率或格式，不悄悄降低规格或改用软件编码。HDR 与鼠标点按显示受公开采集 API 的像素格式限制，不能同时启用。

独立窗口不保证包含独立弹窗或子窗口；最小化或来源应用暂停后台渲染时，不保证画面持续更新。多显示器、HDR 保真、长时间运行和全部异常分支仍需对应场景确认。当前应用应作为早期可运行实现使用，不将一次成功录制视为所有场景均已支持。剪切与拼接是否可直接导出由实际文件和平台能力决定；原件始终保留。

不提供摄像头画中画、暂停续录、直播、云同步、素材库或完整时间线编辑器。突然断电、强制结束进程或未完成封装时，不保证中间 MOV 可恢复。
