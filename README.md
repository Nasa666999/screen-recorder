# Screen Recorder

macOS 轻量录屏工具，使用熟悉的悬浮工具栏选择屏幕、窗口或区域，将系统声音与可选麦克风旁白录入 MOV 文件。

系统声音独立于麦克风，不需要虚拟声卡，也不改变默认音频设备、音量、蓝牙配对或 AirPods 自动切换设置。窗口录制的“系统声音”包含其他应用的声音；受平台保护的内容不能保证采集。

面向 Apple Silicon 和 macOS 26。使用 Swift、AppKit、ScreenCaptureKit 与 AVFoundation，不依赖网络服务或第三方媒体框架。

使用屏幕、窗口或区域模式选择来源，按“录制”开始，从菜单栏停止。系统声音默认开启，麦克风默认为“无”。画质、帧率、倒计时、保存位置、录前确认及缩略图均可在“选项”调整。成品提供应用内播放、基础修剪、系统分享、缩略图拖动复制及移到废纸篓。

全屏和区域使用一条采集流；窗口模式使用独立窗口视频和一条全系统音频流，避免将“系统声音”变成仅窗口所属应用的声音。系统声音和麦克风统一到同一时间线，混为普通播放器直接播放的一条 AAC 音轨。队列有固定上限，不随录制时长累积全部内容。

停止后分别等待 MOV 完成和全部采集流释放。异步调用已发出不代表保存成功；超时会显示实际状态并阻止新录制，不通过重启系统音频或录屏服务收尾。已有文件不覆盖，封装失败的文件不当作成品发布。

## 构建与运行

需要 Apple Silicon、macOS 26 或更高版本，以及包含 macOS 26 SDK 的 Apple Command Line Tools 或 Xcode。

```sh
make build
open "build/Screen Recorder.app"
```

首次创建桌面启动入口可运行 `make desktop-shortcut`。入口指向项目的构建应用，重新构建后仍可使用；已有同名文件时不覆盖。图标使用矢量脚本生成完整尺寸，修改图标源后运行 `make icon` 即可更新。

首次选择来源时，按 macOS 提示授予“屏幕与系统音频录制”权限；只有主动选用麦克风才请求麦克风权限。选择其他保存位置后记住该目录，不改动桌面的 iCloud 设置。

调用快捷键为 `⌘⇧5`。该组合通常被系统“截屏”占用，用户可在系统设置解除原绑定后，从本应用菜单栏右键菜单重试注册；应用不改写系统绑定。停止快捷键为 `⌃⌘Esc`，冲突时使用本应用菜单栏停止按钮。快捷键只在应用运行时有效。

默认使用本地临时签名。重新编译会改变签名身份，macOS 可能要求为新构建重新授权；应用提示与系统列表不一致时，可在系统设置移除本应用的旧授权条目，重新添加当前 `.app` 并退出重开。不会直接修改系统权限数据库。有正式签名身份时，可使用 `make build SIGN_IDENTITY="签名身份名称"`。跨机器分发仍需相应签名与公证。

## 能力边界

“自动”保留来源像素尺寸并使用平台采集和编码能力；尚不承诺编码参数、动态帧率和画质已经逐项等同系统原生录屏。硬件不接受当前规格时明确报错，由用户选择画质、帧率或格式，不悄悄降低规格。HDR 与鼠标点按显示受公开采集 API 的像素格式限制，不能同时启用。

独立窗口的子窗口、最小化、跨 Space、多显示器、HDR 保真、长时间运行和全部异常分支仍需对应场景确认。当前应用应作为早期可运行实现使用，不将一次成功录制视为所有场景均已支持。基础修剪使用无损导出，是否可修剪由实际文件和平台能力决定；原件在导出成功前保留。

不提供摄像头画中画、暂停续录、直播、云同步、素材库或完整时间线编辑器。突然断电、强制结束进程或未完成封装时，不保证中间 MOV 可恢复。
